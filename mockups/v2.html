1 Add to claude_desktop_config.json
// ~/Library/Application Support/Claude/ // claude_desktop_config.json { "mcpServers": { "mcpswag": { "url": "http://localhost:8080/mcp", "type": "http" } } }
2 Restart Claude Desktop
After saving the config, fully quit and reopen Claude Desktop.

McpSwag tools will appear in the tools panel (🔧) when you start a new conversation.
On Windows the config file is at %APPDATA%\Claude\claude_desktop_config.json. On macOS it's at ~/Library/Application Support/Claude/claude_desktop_config.json.
1 Register via CLI (one-time)
claude mcp add mcpswag \ --transport http \ --url http://localhost:8080/mcp
2 Or add to .claude/settings.json
{ "mcpServers": { "mcpswag": { "url": "http://localhost:8080/mcp", "type": "http" } } }
Run claude mcp list to verify the server is registered. Tools become available immediately in new Claude Code sessions — no restart needed.
1 HTTP Streamable transport (MCP 2025-03-26)
# Endpoint POST http://localhost:8080/mcp # Required headers Content-Type: application/json Accept: application/json, text/event-stream
2 Discovery
# List available tools curl -X POST http://localhost:8080/mcp \ -H "Content-Type: application/json" \ -d '{"jsonrpc":"2.0","id":1, "method":"tools/list","params":{}}'
McpSwag speaks the MCP HTTP Streamable transport (spec 2025-03-26). Any client that supports this transport can connect — Cursor, Windsurf, custom agents, etc.
