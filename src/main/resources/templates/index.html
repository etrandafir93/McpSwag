Claude Desktop
Add McpSwag as an MCP server in your Claude Desktop config file.
1
Open the config file
macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
Windows: %APPDATA%\Claude\claude_desktop_config.json
2
Add the McpSwag entry
{ "mcpServers": { "mcpswag": { "url": "http://localhost:8080/mcp", "type": "http" } } }
3
Restart Claude Desktop
Fully quit and reopen Claude Desktop. McpSwag tools will appear in the 🔧 tools panel when you start a new conversation.
Make sure McpSwag is running before starting Claude Desktop. Verify the server is up at http://localhost:8080/mcp.
Claude Code
Register McpSwag via the CLI or by editing your project settings.
1
Option A — register via CLI (recommended)
claude mcp add mcpswag \ --transport http \ --url http://localhost:8080/mcp
2
Option B — edit .claude/settings.json
{ "mcpServers": { "mcpswag": { "url": "http://localhost:8080/mcp", "type": "http" } } }
3
Verify
claude mcp list
Tools are available immediately in new Claude Code sessions — no restart needed.
The CLI command registers McpSwag in your user-level settings (~/.claude/settings.json). Use --scope project to register it only for the current repo instead.
Other MCP client
McpSwag speaks the HTTP Streamable transport (MCP spec 2025-03-26). Any compliant client can connect.
1
Endpoint
POST http://localhost:8080/mcp Content-Type: application/json Accept: application/json, text/event-stream
2
List available tools
curl -X POST http://localhost:8080/mcp \ -H "Content-Type: application/json" \ -H "Accept: application/json" \ -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'
3
Call a tool
curl -X POST http://localhost:8080/mcp \ -H "Content-Type: application/json" \ -d '{"jsonrpc":"2.0","id":2,"method":"tools/call", "params":{"name":"petstore__getPetById","arguments":{"petId":1}}}'
Compatible clients include Cursor, Windsurf, Continue, and any tool that implements the MCP HTTP Streamable transport.
